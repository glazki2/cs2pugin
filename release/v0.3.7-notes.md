# CS2FOW 0.3.7

This is a small visibility-tuning release after 0.3.6. It keeps the same CS2 build compatibility, capsule visibility, smoke behavior, transmit handling, updater, and fail-open safety.

## Update from 0.3.6

Stop the server, extract the ZIP for your operating system into `game/csgo`, then start the server again. Existing configuration values and map bakes can be kept.

## What changed

- The default horizontal AABB padding is now 32 units instead of 8; the upward padding remains 8 units.
- Idle shoulder origins use half the configured base distance. Pressing A expands the left shoulder only, and pressing D expands the right shoulder only. W/S still adds the forward/back movement-origin check without expanding either shoulder.
- Visibility Studio now follows the same capsule, AABB, muzzle, origin, movement, and decision-stage behavior as the native runtime.

The strict CS2 fingerprint gate, 19 animated capsules, smoke/HE behavior, visibility hold, and fail-open behavior are unchanged.

## Release files

- `cs2fow-0.3.7-windows-x86_64.zip` — Windows servers
- `cs2fow-0.3.7-linux-x86_64.zip` — Steam Runtime 3 Linux servers
- `cs2fow-0.3.7-official-maps.zip` — optional ready-made official-map data
- `SHA256SUMS.txt` — integrity checksums
- `v0.3.7-manifest.json` — verified CS2 build, fingerprints, map list, and artifact hashes
