# CS2FOW 0.3.5

CS2FOW 0.3.5 adds safe automatic updates. It supports the same strictly verified CS2 build `24442510` (`1.41.7.3`) on Windows and Linux servers.

## Update from 0.3.4

1. Stop the server.
2. Save a copy of any customized `game/csgo/cfg/cs2fow.cfg`.
3. Download the 0.3.5 ZIP for the server's operating system.
4. Extract it directly into `game/csgo` and allow it to replace the old CS2FOW files.
5. Reapply any custom configuration values and keep `cs2fow_config_loaded` as the final line.
6. Start the server, load a map, and run `cs2fow_status`.

This one update must be installed manually because 0.3.4 does not contain the updater. After 0.3.5 is installed, automatic updates are enabled by default.

## What changed

- CS2FOW checks GitHub's stable releases after startup and every six hours.
- A newer release is accepted only when its exact Windows or Linux package, GitHub SHA-256 digest, CS2FOW release manifest, artifact digest, and current CS2 server-binary fingerprint all agree.
- Verified updates are unpacked in the background. The running plugin is never replaced or hot-reloaded.
- A prepared update installs through a separate bootstrap binary on the next full server restart.
- Future automatic updates preserve known configuration values and map bakes, keep pre-update configuration and plugin-binary backups, and restore the Linux baker and VRF executable permissions.
- Any failed network, compatibility, archive, checksum, or filesystem check leaves the current protection running and retries later.
- `cs2fow_auto_update 1` enables the updater by default. Set it to `0` and run `cs2fow_reload` to disable future checks.

Visibility decisions, capsule and AABB probes, smoke and HE behavior, transmitted entity groups, worker performance settings, strict compatibility enforcement, and fail-open behavior are unchanged from 0.3.4.

## Confirm that it works

Run:

```text
cs2fow_status
```

After the map is ready, the first line should report `CS2FOW 0.3.5: PROTECTED`. The configuration line should report `automatic updates=on`.

If status reports `UPDATE REQUIRED`, the server binary does not match this release's strict verified fingerprints. CS2FOW remains fail-open rather than using unsafe gamedata.

## Release files

- `cs2fow-0.3.5-windows-x86_64.zip` — Windows servers
- `cs2fow-0.3.5-linux-x86_64.zip` — Linux servers
- `SHA256SUMS.txt` — package-integrity checksums
- `v0.3.5-manifest.json` — verified CS2 build, server fingerprints, and artifact hashes

Compiled packages are distributed only as release assets, never through a direct binary link in the README.

## Validation

- Steam's live public CS2 branch is build `24442510` (`1.41.7.3`), matching the exact Windows and Linux gamedata fingerprints in this release.
- Windows and Steam Runtime 3 Linux builds pass native tests, SDK-independent tests, package checks, Windows import checks, SteamRT3 ABI checks, Linux executable-mode checks, and Visibility Studio runtime-alignment checks.
- The GitHub release API supplies SHA-256 digests for the existing release assets, which the updater verifies before staging.
- The README contains no compiled-package download link.
