# CS2FOW 0.3.4

CS2FOW 0.3.4 is a small target-ID safety update for 0.3.3. It supports the same verified CS2 build `24442510` (`1.41.7.3`) on Windows and Linux servers.

## Update from 0.3.3

1. Stop the server.
2. Save a copy of any customized `game/csgo/cfg/cs2fow.cfg`.
3. Download the 0.3.4 ZIP for the server's operating system.
4. Extract it directly into `game/csgo` and allow it to replace the old CS2FOW files.
5. Start with the packaged config and reapply your custom values. If you keep your existing config, add `mp_playerid 1` before the final `cs2fow_config_loaded` line.
6. Start the server, load a map, and run `cs2fow_status`.

The ZIP already contains the correct `addons`, `cfg`, and `tools` folders. No uninstall, client download, database change, or intermediate CS2FOW version is required.

## What changed

- The packaged config now sets `mp_playerid 1`. CS2 therefore shows target IDs for teammates only instead of allowing an enemy name to appear over a hidden player's stale last-transmitted position.
- `cs2fow_status` reports whether target IDs are safe, and `cs2fow_check_config` gives a direct correction when `mp_playerid` is unrestricted.
- The experimental hidden-gunfire filtering was removed before this release. Gunshot sounds and independent shot effects remain outside CS2FOW's filtering boundary.

Visibility decisions, player/equipment filtering, smoke and HE behavior, worker performance, automatic map baking, strict binary fingerprints, and fail-open behavior are unchanged from 0.3.3.

## Confirm that it works

Run:

```text
cs2fow_status
```

After the map is ready, the first line should report `CS2FOW 0.3.4: PROTECTED`, and the protection line should report `target_ids=safe`.

If it reports `target_ids=unrestricted`, run `mp_playerid 1` and add the same setting to `cfg/cs2fow.cfg`. If status reports `UPDATE REQUIRED`, your CS2 server binary does not match this release's strict verified fingerprints.
