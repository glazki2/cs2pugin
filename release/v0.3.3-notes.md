# CS2FOW 0.3.3

CS2FOW 0.3.3 is a compatibility, visibility-quality, and server-operations update for 0.3.1. It supports the current public CS2 build `24442510` (`1.41.7.3`) on Windows and Linux servers.

## Update from 0.3.1

1. Stop the server.
2. Update the CS2 server and Metamod:Source.
3. Save a copy of any customized `game/csgo/cfg/cs2fow.cfg`.
4. Download the 0.3.3 core ZIP for the server's operating system: Windows or Linux.
5. Extract the ZIP directly into `game/csgo` and allow it to replace the old CS2FOW files.
6. Start with the new packaged `cs2fow.cfg`, then reapply only your custom values. Do not restore the old file over it: `cs2fow_config_loaded` must remain its final command.
7. Start the server, load a map, and run `cs2fow_status` in the server console.

The ZIP already contains the correct `addons`, `cfg`, and `tools` folders. They must be directly inside `game/csgo`, not inside another CS2FOW folder.

No uninstall, client download, database change, or intermediate CS2FOW version is required.

## What changed

- **Current CS2 support.** Strict Windows and Linux gamedata was verified against the exact public server binaries. Both verified Linux files Valve distributed for this build are accepted; unknown binaries still stop protection instead of risking unsafe memory access.
- **Full animated body first.** Valve's nineteen live hitbox capsules are now the primary visibility decision. Only when the complete capsule silhouette is blocked does CS2FOW try the eight padded AABB corners and held-weapon muzzle.
- **Longer visibility continuity.** A visible player remains revealed for 1000 ms by default, covering brief LOS gaps such as the CT-to-T angle through Dust II mid doors. Operators can still tune `cs2fow_visibility_hold_ms`.
- **Safer configuration.** The fully commented config loads transactionally. A missing final marker, interruption, or timeout restores the previous known-good settings.
- **Clearer operation.** `cs2fow_status` is now a short health dashboard. `cs2fow_metrics` contains the full technical counters, while `cs2fow_help`, `cs2fow_reload`, and `cs2fow_check_config` cover common administration.
- **Honest Visibility Studio.** Preview and Play use the runtime's real capsule bindings, padded AABB points, muzzle, origins, smoke, HE behavior, and LOS ordering. The old fifteen-point editor and fallback were removed.
- **Reproducible builds.** Windows and Steam Runtime 3 Linux packages use one pinned dependency manifest and the same tested build scripts as GitHub and GitLab CI.

The two-worker default, smoke blocking, HE smoke clearing, teammate filtering, automatic map baking, equipment grouping, and fail-open safety model remain in place.

## Confirm that it works

Run:

```text
cs2fow_status
```

The first line should report `CS2FOW 0.3.3: PROTECTED` after the map is ready. During a first automatic map bake it can temporarily report `BAKING`; everyone remains visible until the new bake passes validation.

If status reports `UPDATE REQUIRED`, update both CS2 and CS2FOW and restart the server. If the command is unknown, confirm that current Metamod:Source is installed and that the ZIP was extracted into the correct folder.
